00 About these koans

TypeScript and Svelte

Files this chapter touches

  • assets/js/hello.ts: greet

Easel is a shared whiteboard, and the koans build it in two languages: TypeScript and Svelte koans in assets/koans/ run under Vitest, Elixir koans in test/koans/ run under ExUnit. One command runs both:

mix koans

It stops at the earliest koan you have not answered, TypeScript before Elixir within a chapter, and prints a footer for it. A value blank is a bare __ inside a koan. A code blank is a __blank("NN: tag") line in assets/js/ or assets/svelte/, between two marker lines that name its chapter: replace that line with your code and keep the markers. Its footer names two places:

Write:          assets/js/hello.ts:3  (00: greet)
Exercised by:   assets/koans/00_about_koans.test.ts:35

Write: is where your code goes, with the blank's tag. Exercised by: is the koan that ran it.

Before any koan runs, svelte-check reads every .ts and .svelte file. A type error stops the run and names its file and line, as a compile error does in Elixir: fix it, then run again. npm test runs only the TypeScript koans, and mix test only the Elixir ones.

API you'll use

  - template literals: `${count} shapes` puts the value of count into the string

Elixir

Files this chapter touches

  • lib/easel/hello.ex: Easel.Hello.greet/1

The Elixir half of the course. Elixir code blanks live in lib/ and test/support/ and work as in the Phoenix course: replace the __(...) line with code and keep the marker lines.

# >>> 07
__("07: list boards newest first")
# <<< 07

Every tag starts with its chapter, in both languages, so one :vimgrep lists a chapter's blanks everywhere (:copen shows them):

:vimgrep /__("07\|__blank("07/ lib/** assets/**

An Elixir footer names the function a blank belongs to, where TypeScript names the tag:

Write:          lib/easel/hello.ex:9  (Easel.Hello.greet/1)
Exercised by:   test/koans/00_about_koans_test.exs:46

Some blanks have a default, as in __("11: subscribe", :ok) or __blank("10: listen", () => {}). Until you fill one it returns the default, so the app keeps working, and it fails only koans of its own chapter, with the same footer.

Run mix phx.server once and open localhost:4000. The name page works from the start; the board pages show a blank on Phoenix's debug page, which is the course talking, not a crash. After 08 you can create a board and open it, after 10 what you draw stays after a reload, and after 12 two windows draw together and list each other. Stop the server and go on.

API you'll use

  - String.split/3: String.split("07: list boards", ": ", parts: 2) is ["07", "list boards"]
